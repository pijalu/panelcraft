## Brand identity refresh

The header now renders **Panel** in the theme foreground and **Craft** with the supplied
lavender-to-purple gradient style. Both gradient endpoints have at least 4.5:1 contrast against
the header in each theme, and forced-colour mode uses ordinary foreground text. The supplied
architecture-diagram PNG is the source for all favicon, installable, maskable and Apple touch
icon sizes; its source hash matches the file supplied for this change and all assets stay local.

Reviewed `test-results/screenshots/m0-light.png`, `m0-dark.png` and the refreshed curated
mini-map/routing captures. Alignment, spacing, theme parity, readable wordmark contrast and the
unchanged template empty state passed the style-guide checklist. The first full browser run
exposed an accessibility defect: an `aria-label` on a roleless span was prohibited. Removing the
unnecessary ARIA overrides left the visible and screen-reader text as `PanelCraft`; the focused
accessibility scenarios passed 12 tests and the final `npx playwright test --reporter=line` run
passed all 259 tests, including offline and installability checks. `npm test` passed 1,731 tests
with coverage thresholds green; `npm run check`, the documentation and self-containment checks,
Go tests, static analysis and complexity checks also passed.
