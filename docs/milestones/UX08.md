# UX-08 — Application experience and flow storytelling

**Status:** In progress — WP01, WP02 and WP03 implemented and verified; WP04–WP15 pending.
**Logged:** 2026-11-15  
**Execution rule:** one agent receives exactly one WP brief below. Do not assign the whole UX-08
scope to one agent or one PR.

## Goals

1. **Trustworthy editing:** selectable grid, complete resize feedback, balanced icon/text,
   accessible link properties, editable connection geometry and legible labels.
2. **Application feel:** compact menus, scrollbar-safe VS Code-inspired panels, responsive
   layout and an installable offline PWA with explicit updates.
3. **Simple storytelling:** visible selection-driven flow creation, automatic presentation with
   optional camera overrides, and documentation for people and agents.
4. **Verified delivery:** failing tests before bug fixes, TS⇄Go format parity, accessible
   light/dark UI, offline self-containment and screenshot review.

## Agent assignment protocol

1. Read `agents.md` and **only the assigned WP brief** plus the source/spec files it names.
2. Keep the change inside that WP. Record a dependency or gap in the WP log instead of
   implementing another WP opportunistically.
3. Use the branch named in the brief. Add GPL SPDX headers and centralized UI strings.
4. Write the stated regression tests first where marked RED. Never weaken an existing test.
5. Run the brief's real checks and paste command/output into its Evidence section before marking
   it done. UI work requires a fresh `npm run build` before Playwright and reviewed screenshots.
6. No new dependency, network storage, external runtime asset, native wrapper or File System
   Access work. PDL and IndexedDB remain the source/persistence model.

## Locked product decisions

- **Object gestures:** double-click/F2 inline rename stays. Request 5 concerns links only.
- **Resize hints:** active object plus every selected object; only the dragged object resizes.
- **Icon layout:** icon at top center; complete label block vertically centered between icon
  bottom and shape bottom padding.
- **Connections:** perimeter endpoints, add/drag/delete bends, orthogonal segment movement and
  optional side/corner/midpoint snapping. Existing PDL anchors/waypoints are sufficient.
- **Grid:** Off/Dots/Lines and snap are independent browser-local UI settings. Grid is editor
  chrome and is excluded from presentation, minimap and document exports.
- **Flows:** existing code is reusable but not accepted as proof of UX correctness. Common path
  needs no raw IDs; all eight step types remain through progressive disclosure.
- **Presentation:** automatic participant/route/label fit by default; optional per-step hold,
  canvas-coordinate focus/zoom, 0–300 ms camera duration, dwell and description. Reduced motion
  applies identical end states immediately.
- **Documentation:** canonical PDL is the agent interface; deterministic Markdown is the human
  export. Camera metadata is not silently represented as Mermaid.
- **PWA:** standalone install, local icons, offline reload and consented restart-to-update. No
  automatic reload or loss of unapplied work.
