## Decisions (binding; errata feed WP10 / FILE-FORMAT.md)

- **D-M1-1 IR JSON canonical form**: fixed key order (TS builders in
  `serialize.ts` ⇄ Go struct field order in `internal/ir/ir.go`); empty arrays
  omitted on both sides; `true`-only booleans (`bidir`, `flip`, `dashed`);
  2-space indent; trailing newline; Go encoder `SetEscapeHTML(false)` so
  `<`, `>`, `&` match `JSON.stringify` output.
- **D-M1-2 doc-level comments**: leading comments before the first meta
  directive serialize under the same `"comments"` key as statement comments.
- **D-M1-3 step union encoding**: flat object with `type` discriminator; keys
  `type, text, from, to, label, linkRef, flip, target, branches, lanes, file,
  flow, ret, comments, pos` — exactly one payload group set (Go: one struct,
  all `omitempty`).
- **D-M1-4 view positions**: `x`/`y` serialize as numbers (0 legal; Go uses
  `*float64` to survive `omitempty`).
- **D-M1-5 fuzzing without new deps**: WP3 property fuzz uses a hand-rolled
  seeded PRNG (deterministic, no `fast-check` dependency ⇒ no ADR needed).
- **D-M1-6 colors vs comments**: `#` + exactly 3/6 hex digits + delimiter lexes
  as COLOR; any other `#` starts a comment. `#` is otherwise unambiguous.
- **D-M1-7 syntax error codes** (abort the file): E100 unexpected, E101
  unterminated string, E102 invalid identifier, E103 bad/missing version,
  E104 unclosed block, E105 unknown top-level statement, E106 invalid escape,
  E107 stray `}` (reserved), E108 invalid arrow, E109 invalid number (reserved
  path), E110 duplicate block attribute, E111 invalid color, E112 nesting
  >32, E113 invalid goto target.
- **D-M1-8 identifiers**: charset `[a-zA-Z][a-zA-Z0-9_-]*` ≤64 (§1 said
  lowercase-only but §4 auto link ids are `L<n>` — uppercase first letter
  allowed; lowercase remains the convention). Overlong runs = E102.
- **D-M1-9 msg-step modifiers order-free**: `: "label"`, `as Ref`, `flip` may
  appear in any order (§14 example writes `as L3 : "label"`; §6 grammar said
  label-first — grammar is normative superset now).
- **D-M1-10 trailing same-line comments** attach to the FOLLOWING statement
  (lexer has no token-boundary lookahead; simple + deterministic).
- **D-M1-11 reversed arrows normalize**: `a <- b` / `a <-t-> b` store
  `from=b, to=a` (+type); canonical printer always prints `->`. `<->` keeps
  endpoints, sets `bidir: true`.
- **D-M1-12 comments inside blocks** accumulate and attach to the next parsed
  statement (possibly the next sibling after `}`); never dropped.
- **D-M1-13 goto target required** (§6 grammar's optional Target is a typo);
  quoted target must be `"path#flowId"`; `return end` is default (not stored).
- **D-M1-14 duplicate meta directives**: first wins, W100 warning (parse-level).
- **D-M1-15 tagged-id lists (tag/contains)** are line-scoped: members must sit
  on the same source line as the keyword (single-line blocks stay parseable).
