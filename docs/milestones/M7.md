## Design decisions

- **Sanitizer: DOM prune over regex** (WP4): fuzz proved regex editing of
  escaped SVG is unsound in both directions (missed `xlink:href
  javascript:`; quote-eating corruption on payloads inside attribute
  values). Canonical path now parses (`image/svg+xml`), prunes
  script/foreignObject/iframe + on*/href/javascript:/srcdoc, re-serializes;
  regex kept only as fallback for unparseable input.
- **Service worker hand-rolled, injected via vite plugin** (WP3, ADR-0004
  stdlib-first): no vite-plugin-pwa; `sw.ts` is typed TS (own
  `tsconfig.sw.json`, WebWorker lib) emitted as transformed text at
  `writeBundle` with `__PRECACHE_MANIFEST__` substituted last (first-use
  replace hit the doc comment — lesson: replaceAll, last).
- **Tab strip is not a tablist** (WP1): ARIA tablist forbids extra
  focusables (close buttons) and axe flags nesting; v1.0 ships plain named
  buttons with visual active state — correct semantics beat pattern
  conformance.
- **N10 scope call**: full string centralization is a mechanical-but-wide
  refactor; doing it at v1.0 freeze trades regression risk for no user
  value. English-only shipped as SPEC allows; centralization groomed to
  v1.1 (SPEC §12).

first test author — semantics are now documented in the test itself.
