- 2025-11-07 — WP4 security:
  - SVG sanitizer **rewritten to DOM-based prune** (parse → drop
    script/foreignObject/iframe + on*/javascript:/srcdoc attrs → re-serialize).
    Fuzz found two real defects in the old regex layer: (1) `xlink:href="javascript:"`
    survived; (2) hostile text inside *escaped* attribute values made the
    regex eat the closing quote, corrupting well-formed docs back into
    malformed markup. Regex pass kept only as fallback for non-well-formed
    input (jsdom XML parser rejects `<` inside attribute values — real
    browsers differ; serializer output is always escaped → DOM path).
  - `web/src/workspace/sanitize.fuzz.test.ts`: 500 seeded hostile-label
    pipeline cases + 13 raw adversarial cases; oracle = structural audit
    (DOMParser walk: no active elements/attrs/script URLs).
  - CLI traversal: `cmd/panelcraft/traversal_test.go` — Classify escape table
    (relative climbs, nested `from` bases; absolutes clamp INTO workspace =
    safe, documented in test) + `panelcraft validate --json` e2e (exit 1,
    P103 error-severity). Server /files traversal covered by
    TestFilesNoListingNoTraversal.
  - Evidence: `bash scripts/verify.sh m7 svg_fuzz cli_traversal` → ALL GREEN.
