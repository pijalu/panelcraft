## Design decisions

- **Plan/executor split** (handover d): `engine/flows/plan.ts` is pure — parsed
  Doc + flow in, flat `Beat[]` out (index, kind, narration title, actors,
  resolved links, dim set, delayMs; par lanes as `Beat[][]` sub-lists). The
  executor (`engine/anim` + `ui/`) owns DOM and timers.
- **Dim semantics**: beats with no participants (intro/info/conclusion/goto/
  alt-chooser) dim NOTHING (FR-F2 overview / un-dim); focus beats dim every
  non-participating object+link id. Dim order = universe order (objects, then
  links) for deterministic assertions.
- **Canvas-side link ids**: `canvasLinkId(l, i) = l.id ?? from-to-i` exported
  from plan.ts — the same rule as workspace `docToState`, so beats address
  rendered `g.pc-link[data-id]` elements directly (single source of truth).
- **flip**: step-written direction reversed — travel = stepTo→stepFrom when
  `flip` (FILE-FORMAT §6 "plays the step reversed"); underlying link untouched.
- **goto**: cross-file target syntax is `goto "path.pcd#flowId"` (single
  quoted token — parser rejects bare dotted paths). Resolver injected
  (`FlowResolver`), so the executor supplies workspace lookup; `return here`
  semantics decided at executor level (planned: pop + replay the goto beat).
  Shipped: pop re-runs the popped beat's visuals without re-triggering its
  goto, then auto-advance resumes; `return flow` pushes a nested Frame.
- **Alt choices** keyed by chooser-beat index (string path from `collectAlts`);
  default = first branch; choice never stored (FILE-FORMAT §6).
- **stepTo parks paused**: manual stepping cancels the auto-advance timer —
  stepping is a determinism tool (e2e) and a review feature; `resume()`
  (or choosing an alt branch, which advances as `playing`) restarts timers.
- **Step reorder via buttons, not drag**: `step-up`/`step-down` keep the
  inspector a keyboard-reachable flat list; drag reordering would need a
  second pointer protocol against the sidebar (M6 candidate).
- **Inspector-seeded ids**: adding a msg/process step seeds `from`/`to`/
  `target` with real object ids (first objects in the doc) so the printed
  text always re-parses — an empty target would abort the whole file parse.
- **onCtrlState projection dedupe (M5 fix)**: the canvas emits its snapshot
  on every render/selection/camera change; persisting the flow-less
  projection on each emit clobbered the file's full text (flows lost — S3
  originally saw the FlowPane list read the `-uses->` projection). The
  M3 bridge now persists via `saveCanvas` only when the serialized
  projection actually changed; noise emits are dropped. Canvas edits still
  win (D-M4-6 unchanged), camera still bypasses the bridge via
  `applyCamera` (no emit).
- **Timings**: `engine/anim/timings.ts` `MOTION` = theme config (FR-F3/F4);
  plan defaults `delayMs` from it; CSS mirrors values (WP7 polish).

## Icon license note (M5-WP6, ADR-0005)

The 8 inline SVG glyphs (cloud, database, gear, lock, mail, user, chart, code)
are **original in-repo works** drawn for PanelCraft — not copied from any
icon collection — so no third-party license obligation applies. Every
`web/assets/icons/*.svg` and every M5 source file carries
`SPDX-License-Identifier: GPL-3.0-only`. Only the path data is embedded
(`icons.ts`), rendered as inline `<path>` elements — no icon fonts, no
external requests. `icons.test.ts` asserts module/assets lockstep so the
inline copies cannot drift from the reviewed sources.
