# Choice Overload

## Concise explanation

Too many similarly prominent options increase decision effort and can prevent action. The
problem is the decision context and presentation, not merely a fixed number of choices.

## PanelCraft application

Prioritize common canvas and file actions, group advanced properties, and use searchable or
progressively disclosed controls for infrequent operations without removing capability.

## Common failure modes

- Showing every command at equal priority in one toolbar or menu.
- Duplicating options without clear differences or defaults.
- Hiding essential recovery actions while reducing visible choices.

## Review questions

- Can users identify the likely next action without comparing unrelated options?
- Are advanced choices grouped, named, and recoverable?
