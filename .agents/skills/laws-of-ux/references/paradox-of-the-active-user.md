# Paradox of the Active User

## Concise explanation

Users often begin tasks before learning the whole system, even when study would save time
later. Interfaces must support learning through action and safe recovery.

## PanelCraft application

Make initial canvas editing productive with sensible defaults, inline hints, discoverable
commands, reversible actions, and contextual links to concise PDL guidance.

## Common failure modes

- Requiring a long tutorial or format documentation before first use.
- Hiding essential recovery behind unfamiliar expert shortcuts.
- Punishing experimentation with destructive or unrecoverable edits.

## Review questions

- Can a new user complete a small useful task immediately?
- Does exploration preserve data and teach the underlying model?
