# Miller’s Law

## Concise explanation

Immediate memory has limited capacity; the often-cited seven-plus-or-minus-two figure is not
a universal interface limit. Meaningful organization matters more than enforcing a magic
number of items.

## PanelCraft application

Avoid requiring recall of object IDs, long step sequences, or hidden diagnostics. Use visible
context, meaningful grouping, search, and summaries instead of arbitrary list truncation.

## Common failure modes

- Limiting every menu or list to seven items regardless of the task.
- Showing long raw identifiers or ungrouped properties that burden recall.
- Confusing working-memory limits with a universal design quota.

## Review questions

- What information must users hold in memory, and why?
- Can grouping or persistent context reduce that demand?
