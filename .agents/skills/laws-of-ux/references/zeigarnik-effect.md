# Zeigarnik Effect

## Concise explanation

Unfinished tasks can remain more mentally salient than completed ones. Visible pending state
can support resumption, but unresolved indicators also create distraction when inaccurate.

## PanelCraft application

Preserve and expose unsaved edits, incomplete imports, paused flows, and recoverable workspace
state. Clear stale progress or diagnostic indicators as soon as the task actually resolves.

## Common failure modes

- Leaving dirty chips, spinners, or warnings visible after successful recovery.
- Using artificial incomplete states to pressure continued engagement.
- Closing a view and losing unfinished work or its recovery path.

## Review questions

- Is unfinished work accurately represented and easy to resume?
- Do completion, cancellation, and failure each clear or preserve state appropriately?
