# Law of Similarity

## Concise explanation

Similar visual characteristics suggest related meaning or behavior. Consistency helps users
predict interactions; misleading similarity creates false expectations.

## PanelCraft application

Give equivalent buttons, fields, object states, and flow cards consistent treatments. Distinguish
selection, import ghosts, errors, and links using shape or text as well as color.

## Common failure modes

- Using the same accent for selection, warning, and primary action.
- Making visually identical controls behave differently.
- Encoding meaning by color alone.

## Review questions

- Do similar-looking elements actually share meaning and behavior?
- Are important differences understandable without color perception?
