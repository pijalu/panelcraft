# Chunking

## Concise explanation

Grouping related information into meaningful units makes content easier to scan, understand,
and remember. Useful chunks reflect the user's task rather than arbitrary visual divisions.

## PanelCraft application

Group object identity, style, and advanced fields; organize flow steps and workspace files
into meaningful structures; keep code statements and their visual counterparts associated.

## Common failure modes

- Creating boxes that do not correspond to meaningful task groups.
- Splitting tightly related controls across distant panels.
- Over-nesting groups until navigation becomes harder.

## Review questions

- Does each group have a clear purpose and label?
- Can users compare or edit related values without unnecessary navigation?
