# Hick’s Law

## Concise explanation

Decision time generally grows with the number and complexity of alternatives. Relevant
categorization and familiar defaults can reduce the decision burden without hiding capability.

## PanelCraft application

Use focused menus, sensible connector defaults, and contextual properties. Separate frequent
shape and flow actions from specialized commands, with clear names and search where useful.

## Common failure modes

- Putting every possible action into one undifferentiated menu.
- Removing advanced options instead of organizing them.
- Creating categories whose labels do not help users predict contents.

## Review questions

- Are options ordered and grouped around recognizable user intents?
- Is the default safe and useful for the common case?
