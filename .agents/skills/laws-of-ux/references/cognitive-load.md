# Cognitive Load

## Concise explanation

Working memory and attention are limited. Interfaces should reduce effort unrelated to the
user's goal while preserving the complexity intrinsic to architecture modeling.

## PanelCraft application

Keep canvas/code synchronization visible, avoid redundant ID transcription, preserve context
during edits, and make validation messages actionable rather than forcing mental mapping.

## Common failure modes

- Requiring users to remember hidden selection or panel state.
- Displaying competing badges, diagnostics, and decoration without hierarchy.
- Simplifying the model by removing necessary information or control.

## Review questions

- What must users remember between steps, and can the interface show it instead?
- Does each visual element support the current modeling task?
