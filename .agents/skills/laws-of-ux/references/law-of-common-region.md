# Law of Common Region

## Concise explanation

Elements within a shared boundary tend to be perceived as related. Boundaries can clarify
structure, but unnecessary containers add noise and can create false associations.

## PanelCraft application

Use panel and field-group boundaries to distinguish identity, metadata, style, flow branches,
and dialog content. Ensure nested groups and selected objects retain clear visual ownership.

## Common failure modes

- Grouping unrelated controls simply because space is available.
- Nesting borders until boundaries compete with content.
- Relying on a region without an accessible group name.

## Review questions

- Does each container communicate a real relationship?
- Is the grouping also conveyed semantically to assistive technology?
