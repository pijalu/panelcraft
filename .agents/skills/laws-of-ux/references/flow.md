# Flow

## Concise explanation

Absorption in a meaningful activity is supported by clear goals, immediate feedback, and a
balance between challenge and capability. Interface interruptions break that continuity.

## PanelCraft application

Preserve canvas/code context, coalesce routine undo history, avoid unexpected focus changes,
and make repetitive modeling operations efficient for both pointer and keyboard users.

## Common failure modes

- Interrupting editing with nonessential dialogs or notifications.
- Losing selection, caret, scroll, or panel state after routine actions.
- Removing useful control in an attempt to make the interface effortless.

## Review questions

- Can users complete a sequence of edits without recovering context?
- Does feedback arrive at the right moment without stealing focus?
