# Cognitive Bias

## Concise explanation

Systematic patterns in attention and judgment shape how people interpret interfaces. Design
and review can also be distorted by confirmation, familiarity, framing, and recency biases.

## PanelCraft application

Test defaults, warning wording, selection states, and diagram interpretations with evidence
from users and observable behavior. Include reviewers with different product familiarity.

## Common failure modes

- Designing only for the author's preferred workflow.
- Treating the first test result or loudest opinion as representative.
- Framing validation so that only confirming evidence is collected.

## Review questions

- What evidence could disprove the current design assumption?
- Do labels and defaults avoid steering users toward unintended conclusions?
