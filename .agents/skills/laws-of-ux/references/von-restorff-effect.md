# Von Restorff Effect

## Concise explanation

An item that differs noticeably from similar surroundings is more likely to be noticed and
remembered. Contrast is most effective when reserved for genuinely important distinctions.

## PanelCraft application

Emphasize primary actions, selected objects, active flow participants, and serious diagnostics
with restrained, consistent treatments that include text, shape, or icon cues.

## Common failure modes

- Making many elements equally distinctive until none stands out.
- Using accent or red color alone to convey state.
- Highlighting decoration more strongly than the actual problem or action.

## Review questions

- What single distinction matters most in this state?
- Is emphasis accessible, consistent, and removed when no longer relevant?
